# 绩效成果填报低保真原型

- 入口：首页 [index.html](./index.html)
- 页面：
  - 实验室工作台 [lab-inbox.html](./lab-inbox.html)：匹配/新建/进度
  - 成果匹配 [match-dialog.html](./match-dialog.html)：库内检索与选择
  - 填报表单 [fill-form.html](./fill-form.html)：字段与附件示例
  - 二级单位审核 [unit-inbox.html](./unit-inbox.html)：批量与单条审核
  - 审核面板 [review-unit.html](./review-unit.html)：校验与意见
  - 汇总报表 [reports.html](./reports.html)：统计与导出入口

打开方式：用浏览器直接打开 index.html 即可完成原型体验。

说明：该原型用于展示信息架构与关键交互，字段与校验为示例，可据口径配置扩展。
